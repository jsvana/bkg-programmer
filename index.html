Power-on modes

Your radio starts up differently depending on which button you hold while turning it on. This tool can only make changes when the radio is in programming mode.

  • No buttonNormal useTurn it on as usual — transmit, receive, menus. This tool can’t talk to the radio in this mode.
  • Hold PTTInstall modeHold the PTT (push-to-talk) key while powering on. This is for installing firmware with UVTools2. You won’t use this mode here directly.
  • Hold Side 2Programming mode needed for this toolHold the lower side button (Side 2) while powering on. The radio then waits for this tool to read and change its settings. Only available once custom firmware is installed — install it first if your radio still has the factory firmware.
